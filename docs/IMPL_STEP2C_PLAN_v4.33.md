# v4.33 구현 2c — 사람용 셀 작업 계획 (제안)

대상은 A0 Colab 사람용 노트북 `eggplant_yolo_colab_v4.32.0.ipynb`의 0~34번 셀입니다. v4.33 노트북을 새로 만들고, 옛 노트북은 그대로 둡니다.

**목표 (DESIGN '셀 분류'):** 사람이 셀을 실행하면 기본은 **분석 모드**입니다.
- 공유 폴더(BASE)는 읽기만 합니다. 결과는 자기 분석 폴더 `analysis/<M>/<날짜>_<세션>/`에만 씁니다.
- CVAT는 허용 목록에 있는 읽기와, 참조용 export 준비·받기만 씁니다.
- CVAT·공유 상태를 바꾸는 일은 모두 **요청**, **'이 결과 올리기'(고정 제출본)**, **신호**로 바꿉니다. 실제로 바꾸는 것은 실행기(30번 셀·GPU·CPU 작업 프로세스)입니다.
- 30번 셀을 켜면 실행기가 됩니다(2b-6의 `cell30_v4.33.py`).

점검표의 A(실행 컨텍스트)·B(파일 쓰기)·C('이 결과 올리기')·D(모델·데이터셋 읽기 보호)와 F2의 '읽는 쪽 전환'을 이 단계에서 닫습니다.
